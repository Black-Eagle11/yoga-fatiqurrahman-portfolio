# Yoga Fatiqurrahman — Portfolio Web

Website ini dibuat untuk **Tugas 2 Portofolio Web** mata kuliah Teknologi Web.

## Identitas

- Nama: Yoga Fatiqurrahman
- Program Studi: Ilmu Komputer
- Institusi: Universitas Pendidikan Ganesha (Undiksha)

## Struktur halaman

- `dist/index.html` — landing page / beranda.
- `dist/about.html` — profil dan catatan penerapan konsep Tailwind.
- `dist/projects.html` — proyek Sentiment Analysis, LAUNDRILY, dan Frontend Lab.
- `dist/javascript.html` — tugas JavaScript berupa kalkulator target IPK interaktif.
- `dist/assets/styles.css` — CSS tambahan untuk tema, animasi, dan aksesibilitas.
- `dist/assets/app.js` — menu responsif, navigasi aktif, animasi reveal, dan tahun footer.

## Konsep Tailwind yang digunakan

Website menggunakan utility class Tailwind melalui CDN:

1. Styling with Utility Classes — padding, margin, border, radius, typography, dan background.
2. Responsive Design — breakpoint `sm:`, `md:`, dan `lg:`.
3. Hover, Focus & Other States — `hover:`, `focus-visible`, dan state validasi input/kalkulator.
4. Colors — warna teks, background, border, dan aksen.
5. Spacing — `gap-*`, `p-*`, `m-*`, dan `space-y-*`.
6. Sizing — `max-w-*`, `min-h-*`, `w-*`, dan ukuran teks.
7. Flexbox — navbar, tombol, badge, dan alignment.
8. Grid — layout kartu, statistik, dan layout halaman.

## Menjalankan di VS Code

1. Buka folder project di VS Code.
2. Buka `dist/index.html` dengan Live Server, atau buka langsung di browser.
3. Pastikan koneksi internet aktif karena Tailwind dimuat melalui CDN.
4. Buka menu **JavaScript Lab** untuk mencoba kalkulator target IPK.

Tidak diperlukan backend, database, atau instalasi package untuk menjalankan versi statis ini.
