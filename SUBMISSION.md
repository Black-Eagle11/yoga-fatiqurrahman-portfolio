## Ringkasan

Website portofolio responsive dengan empat halaman:

1. Beranda / landing page
2. Tentang
3. Proyek
4. JavaScript Lab — Kalkulator Target IPK

Website dibuat menggunakan HTML, Tailwind CSS, CSS kustom, dan JavaScript. Fitur JavaScript mencakup manipulasi DOM, event handling, validasi, percabangan, kalkulasi, dan `localStorage`.

## Fitur JavaScript

Kalkulator menghitung IPS minimum berdasarkan total SKS saat ini, IPK saat ini,
jumlah SKS berikutnya, dan target IPK. Fitur ini menerapkan manipulasi DOM,
event handling, validasi input, percabangan, kalkulasi, dan `localStorage` untuk
menyimpan lima riwayat simulasi terakhir.
